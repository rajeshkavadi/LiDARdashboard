Launch RViz with the LiDAR view

rviz -d ~/rviz_web_app/ros_pkg/lidar_web_bridge/rviz/lidar_view.rviz

The config uses Fixed Frame livox_frame and a PointCloud2 display on /livox/lidar, colored by Z with size 2.

Existing workflow

roslaunch lidar_web_bridge lidar_web.launch rviz:=true

This starts the bridge node and RViz. Your existing Livox driver keeps publishing to /livox/lidar; nothing in the driver is changed.
